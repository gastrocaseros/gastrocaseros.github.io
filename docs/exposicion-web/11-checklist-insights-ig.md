# Checklist — Instagram Insights (90 días)

Hacer **una vez**. Objetivo: confirmar si IG aporta turnos/tests o solo alcance.  
Fecha de captura: _______________ · Período: últimos **90 días**

## Dónde mirar (app celular)

1. Perfil → menú (≡) → **Insights** / **Profesional** → **Ver todo**.  
2. Si pide rango: **Últimos 90 días**.  
3. Capturar pantalla de cada bloque abajo (o anotar el número).

## Lectura rápida (sin vanidad)

| Señal | Interpretación |
|-------|----------------|
| Link taps + DMs de turnos/tests ≈ **0** | IG = marca/soporte; no invertir en cadencia |
| Link taps o DMs de tests **> 0** pero bajos | Mantener ≤2 piezas Tests/mes; medir otra vez en 90d |
| Top guardados = SIBO/IMO o pylori | Repetir ese **ángulo** de tema (no el formato de post) |
| Top alcance = efemérides patrias | Alcance ≠ pacientes; no priorizar patrias |
